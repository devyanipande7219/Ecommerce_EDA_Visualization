# Ecommerce EDA Visualization

## Project Overview

This project focuses on analyzing an e-commerce dataset using Python to understand sales patterns, customer behavior, product categories, order status, and generate meaningful insights through data analysis and visualization.

## Objectives

- Perform data cleaning and preprocessing
- Explore the e-commerce dataset
- Analyze customer demographics and purchasing patterns
- Analyze product categories and sales performance
- Examine order status and delivery trends
- Create meaningful visualizations
- Generate insights from the data

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files

- `Ecommerce EDA&Visualization.ipynb` — Jupyter Notebook containing the complete analysis
- `eCommerce Store.xlsx` — Dataset used for the analysis

## Analysis Process

1. Data loading
2. Data inspection
3. Data cleaning and preprocessing
4. Exploratory Data Analysis (EDA)
5. Customer and product analysis
6. Sales and order analysis
7. Data visualization
8. Insight generation

## Key Skills Demonstrated

- Data Cleaning
- Exploratory Data Analysis
- Data Visualization
- Python Data Analysis
- Pandas
- Matplotlib
- Seaborn

## Key Insights

- Analyzed sales patterns across different product categories.
- Studied customer distribution based on gender and age.
- Analyzed sales across different shopping channels.
- Examined order status and delivery trends.
- Identified important patterns and trends through visualizations.

## Conclusion

This project demonstrates the use of Python, Pandas, Matplotlib, and Seaborn for data cleaning, exploratory data analysis, and visualization to extract meaningful business insights from an e-commerce dataset.
